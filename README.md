# Лабораторная работа 2: потоковое шифрование на основе LFSR

Программа реализует систему потокового шифрования и дешифрования файлов с любым содержимым и расширением. Ключевая последовательность генерируется с помощью линейного сдвигового регистра с обратной связью LFSR.

## Используемый многочлен

```text
x^32 + x^28 + x^27 + x + 1
```

Размер регистра: `32` бита.

Обратная связь вычисляется как:

```text
b31 XOR b27 XOR b26 XOR b0
```

На каждом такте выходным битом является младший бит регистра `b0`, после чего регистр сдвигается вправо, а новый бит обратной связи записывается слева.

## Возможности

- шифрование файла любого типа;
- расшифрование файла любого типа;
- ввод начального состояния LFSR с клавиатуры;
- автоматическая фильтрация поля состояния: принимаются только символы `0` и `1`;
- сохранение зашифрованного или расшифрованного результата на диск в виде потока байтов;
- вывод в интерфейсе ключа, исходных данных и результата в двоичном виде.

## Требования

- Python 3;
- стандартная библиотека Python;
- модуль `tkinter`.

Дополнительные библиотеки устанавливать не нужно.

## Запуск

В папке проекта выполнить:

```bash
python lab2.py
```

После запуска откроется графическое окно программы.

## Как пользоваться

1. Введите начальное состояние регистра из `32` битов.
2. Выберите исходный файл.
3. Укажите путь для файла результата.
4. Нажмите:
   - `Зашифровать файл` для шифрования;
   - `Расшифровать файл` для дешифрования.

Для расшифровки нужно использовать то же начальное состояние регистра, которое использовалось при шифровании.

## Принцип работы

Программа генерирует ключевой поток с помощью LFSR. Затем каждый байт исходного файла складывается с соответствующим байтом ключа операцией XOR:

```text
result_byte = source_byte XOR key_byte
```

Дешифрование выполняется той же операцией:

```text
source_byte = encrypted_byte XOR key_byte
```

Это работает потому, что операция XOR обратима:

```text
(A XOR K) XOR K = A
```

## Вывод данных

В интерфейсе отображаются:

- ключевая последовательность;
- исходный файл в двоичном виде;
- результат в двоичном виде.

Чтобы программа не зависала при обработке больших файлов, например видео, в каждом поле выводятся первые `60` байтов данных. При этом сам файл обрабатывается полностью, а результат полностью сохраняется на диск.
